## 关于我们

多媒体智能前沿实验室（M<sup>3</sup>AIL Research Group）隶属于哈尔滨工业大学（深圳）智能科学与工程学院，由学院院长、国家杰出青年科学基金获得者俞俊教授领衔，于 2024 年成立。

实验室聚焦多模态智能、具身智能、世界模型、大模型、智能体、可控视频生成与编辑、医学影像分析及跨域感知等研究方向，致力于推动人工智能在多媒体计算、智能感知及实际应用中的创新发展。
